		\subsection{Microcontrolador STM32F446RE}

			El STM32F446RE es un microcontrolador de alto rendimiento basado en ARM Cortex-M4 con:

			\begin{itemize}
				\item Núcleo: Cortex-M4 con soporte para FPU (unidad de punto flotante de 32 bits)
				\item Frecuencia de operación: Hasta 180 MHz
				\item Memoria Flash: 512 KB
				\item Memoria RAM: 128 KB
				\item Periféricos: ADC de 12 bits, DAC de 12 bits, múltiples timers, DMA, UART
			\end{itemize}

			En este proyecto se opera a 90 MHz (dividido del reloj máximo de 180 MHz) para mantener márgenes de estabilidad.

		\subsection{Convertidor Analógico-Digital (ADC1)}

			\begin{itemize}
				\item Resolución: 12 bits
				\item Rango: 0 a 3.3V (mapeado a 0 a 4095 digital)
				\item Frecuencia de muestreo: 16 kHz
				\item Fuente de trigger: Salida TRGO de TIM2
				\item Modo: DMA en circular (double-buffering)
				\item Buffer: 512 muestras (256 por semibuffer para procesamiento)
			\end{itemize}

			La normalización a rango [-1, +1] se realiza mediante:

			\[
			s(n) = \frac{\text{ADC}(n) - 2048}{2047.5}
			\]

		\subsection{Convertidor Digital-Analógico (DAC)}

			\begin{itemize}
				\item Resolución: 12 bits
				\item Rango: 0 a 3.3V
				\item Canales: 2 (CH1 para e(n), CH2 para d(n))
				\item Modo: DMA doble para transmisión continua
				\item Actualización: Sincronizada con ADC mediante TIM2
			\end{itemize}

			La conversión de punto flotante a 12 bits se realiza como:

			\[
			\text{DAC}(n) = \lfloor (f(n) + 1.0) \times 2047.5 + 0.5 \rfloor
			\]

			clampando el resultado entre 0 y 4095.

		\subsection{Timer 2 (TIM2)}

			\begin{itemize}
				\item Configuración: Contador de 32 bits (máxima resolución)
				\item Función: Generar salida TRGO cada período para disparar ADC
				\item Frecuencia: 16 kHz
				\item Cálculo de período: ARR = $\frac{f_{CLK}}{f_{deseada}} - 1 = \frac{90 \times 10^6}{16 \times 10^3} - 1 = 5624$
			\end{itemize}

		\subsection{Acceso Directo a Memoria (DMA2)}

			\begin{itemize}
				\item Stream 0: ADC → buffer RAM (modo circular)
				\item Stream 6 y 7: RAM → DAC (modo circular para dual DAC)
				\item Modo: Circular con generación de interrupciones Half y Full Transfer
				\item Ancho de dato: 16 bits
			\end{itemize}

			El modo circular permite que DMA actualice continuamente los buffers sin intervención del CPU, minimizando latencia y jitter.
